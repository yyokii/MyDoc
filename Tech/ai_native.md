# AI Native

## [AI企業が「受託」を始めた日。エンジニア、PM、デザイナーはどうこの先生きのこるか](https://note.com/fladdict/n/nd42977e5443e)

* OpenAI / Anthropic が API 提供だけでなく、企業現場に入り込み AI を業務中核に組み込む「受託・導入」へ動いている
* 新しい産業を作るより、すでに儲かっている産業（金融・法務・開発運用・CS など）に入り、利益率を変えるほうが合理的
* コンビニの PB 戦略に近い：API で市場を見て、金が動く業務を自社化・合弁・買収・FDE で取りにいく
* 「ドメイン知識があるから大丈夫」は短期では正しいが、資本視点ではその会社を買えばよい。AI に置き換わらない仕事も、AI から呼び出される人間モジュールになりうる
* 会社は残っても職位は残らないかもしれない。自動適応製品が出た瞬間に移行需要は終わりうる

### どう生き残るか

* 「AIにできない作業」探しは時間稼ぎにしかならない
* AIを含むシステム全体の責任に近づく：業務をAIが扱える構造に翻訳し、人間とAIの分担・責任線を設計する
* エンジニアは「業務を計算可能にする人」、PMは「変化の順番を設計する人」、デザイナーは「人間がAIを信頼・監督・修正できる関係を作る人」へ
* 毎週自分の作業をAIに渡し、自分自身を自動更新する
